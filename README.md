# CALOHA - Tinh Dầu Thiên Nhiên & Trị Liệu Hữu Cơ

CALOHA là website thương mại điện tử và cẩm nang trị liệu mùi hương cao cấp, cung cấp 62 dòng tinh dầu nguyên chất, dầu nền thực vật và bài viết chuyên sâu về liệu pháp mùi hương (Aromatherapy).

## ✨ Tính Năng Nổi Bật

- **Trang chủ & Banner tương tác:** Giới thiệu triết lý sản phẩm, bộ sưu tập theo nhóm hương (Cam Chanh, Hương Hoa, Hương Gỗ, Thảo Mộc, Dầu Nền).
- **Bộ sưu tập 62 sản phẩm:** Bộ lọc đa năng theo nhóm hương, dung tích, tầm giá và tìm kiếm thông minh theo từ khóa.
- **Xem chi tiết sản phẩm (Quick View & Kính lúp):** Phóng to ảnh chi tiết 2x, trình xem ảnh toàn màn hình (Lightbox), thông số chi tiết (xuất xứ, phương pháp chiết xuất, nốt hương, công dụng).
- **Giỏ hàng & Đặt hàng nhanh:** Drawer giỏ hàng trượt mượt mà, tính toán chi phí và biểu mẫu đặt hàng.
- **Hệ thống bài viết & Cẩm nang:** Hướng dẫn phân biệt tinh dầu, tỷ lệ pha loãng an toàn và bài viết so sánh các loại tinh dầu.
- **Trang Giới thiệu & Liên hệ:** Kể câu chuyện nông trại chưng cất, bản đồ showroom, hotline và form tư vấn 1-1.

## 🚀 Khởi Chạy Dự Án

Yêu cầu máy tính đã cài đặt [Node.js](https://nodejs.org/).

1. Mở thư mục dự án trên máy tính:
   ```bash
   cd caloha-essential-oils
   ```
2. Chạy máy chủ cục bộ:
   ```bash
   node server.js
   ```
3. Truy cập trình duyệt tại địa chỉ:
   ```
   http://localhost:3000
   ```
